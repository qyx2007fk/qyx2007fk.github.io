第一次用？点这里看怎么创建 token
  1. 打开 GitHub 新建 Fine-grained token。
  2. Token name 随便写，Expiration 选 7 天或 30 天。
  3. Repository access 选 Only select repositories，只勾 qyx2007fk.github.io。
  4. Repository permissions → Contents 选 Read and write；Metadata 会自动是 Read。
  5. Generate token，复制 github_pat_... 回来粘贴。

这个 token 只能改这个仓库的内容。不要把 token 发到任何聊天窗口；如果泄露，立刻去 GitHub 删除。
